# QuestVision for Baldur's Gate 3

**Dynamic quest NPC detection and visualization mod.**

## Features (planned v1.0)
- 🔍 Automatic detection of quest-related NPCs without hardcoded lists
- 🟡🟢🔵🔴 Color-coded NPC highlighting
- 📡 Quest Radar overlay
- ⚙️ MCM configuration menu
- ⌨️ Hotkey toggle (default F9)

## Current Status
🚧 Pre-alpha — Core architecture and Quest Detection Engine in development.

## Requirements
- Baldur's Gate 3 (latest patch)
- [Norbyte's BG3 Script Extender](https://github.com/Norbyte/bg3se)

## Installation (development)
1. Copy `ScriptExtender` folder into your BG3 `Data/` directory.
2. Launch the game. Check `%LocalAppData%\Larian Studios\Baldur's Gate 3\Script Extender\Logs\` for debug output.
